# حریم خصوصی و داده‌ها

## داده‌های ذخیره‌شده

داده‌های شخصی در این جدول‌ها نگه‌داری می‌شوند (با پیشوند جدول وردپرس، مثلاً `wp_`):

| جدول | داده‌های شخصی |
|---|---|
| `pronobat_customers` | نام، تلفن، ایمیل، کد ملی (اختیاری)، تاریخ تولد (اختیاری)، یادداشت، وضعیت opt-out |
| `pronobat_appointments` | یادداشت مشتری و یادداشت مدیر، پیوند به `customer_id` |
| `pronobat_notifications_log` | گیرنده‌ی پیامک/ایمیل و متن پیام ارسالی |

<Callout type="info">
همه‌ی زمان‌ها به‌صورت UTC ذخیره و فقط هنگام نمایش به وقت تهران تبدیل می‌شوند.
</Callout>

## صادر کردن داده (Export)

از صفحه‌ی **پرونوبت ← مشتریان**، با باز کردن پروفایل یک مشتری می‌توانید داده‌ی او را به‌صورت JSON خروجی بگیرید. این عملیات از endpoint زیر استفاده می‌کند:

```
GET /wp-json/pronobat/v1/customers/{id}/export
```

**دسترسی:** `pronobat_manage` + `X-WP-Nonce`

پاسخ شامل اطلاعات مشتری و تمام نوبت‌های او (تا ۵۰۰ مورد) به‌همراه زمان خروجی است.

<Callout type="warning">
پرونوبت در حال حاضر با ابزار بومی «صادر/حذف داده‌ی شخصی» وردپرس یکپارچه نیست؛ خروجی و ناشناس‌سازی فقط از طریق صفحه‌ی مشتریان یا endpoint های افزونه انجام می‌شود.
</Callout>

## ناشناس‌سازی (Anonymize)

```
POST /wp-json/pronobat/v1/customers/{id}/anonymize
```

**دسترسی:** `pronobat_manage`

این endpoint رکورد مشتری را این‌گونه تغییر می‌دهد:

1. نام کوچک را به `[anonymized]` و نام خانوادگی را به مقدار خالی تغییر می‌دهد
2. تلفن را با یک مقدار جای‌گزین یکتا (`0900000` + شناسه) بازنویسی می‌کند
3. ایمیل و یادداشت‌ها را خالی می‌کند
4. اکشن `pronobat_customer_anonymized` را فراخوانی می‌کند

نوبت‌های گذشته برای اهداف حسابداری حفظ می‌شوند، اما دیگر به اطلاعات شخصیِ قابل‌شناسایی متصل نیستند.

## پاک‌سازی خودکار لاگ

کرون پاک‌سازی به‌صورت دوره‌ای رکوردهای قدیمی `notifications_log` (قدیمی‌تر از حدود یک سال) و نوبت‌های `pending_payment` منقضی‌شده را حذف می‌کند. این رفتار خودکار است و تنظیمات جداگانه‌ای ندارد.

## حذف افزونه

<Callout type="warning">
هنگام **حذف** افزونه از وردپرس (Delete، نه صرفاً غیرفعال‌سازی)، فایل `uninstall.php` به‌طور کامل و **غیرقابل‌بازگشت** اجرا می‌شود: تمام جدول‌های پرونوبت، گزینه‌ها، ترنزینت‌ها، نقش‌ها و متادیتای کاربران حذف می‌شوند. پیش از حذف، در صورت نیاز از داده‌ها پشتیبان بگیرید.
</Callout>
