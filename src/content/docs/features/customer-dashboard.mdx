# داشبورد مشتری

با شورت‌کد `[pronobat_appointments]` یک داشبورد تعاملی به مشتری می‌دهید تا خودش نوبت‌هایش را مدیریت کند — بدون تماس تلفنی.

```
[pronobat_appointments]
```

## امکانات

- تب‌های **«پیش‌رو»** و **«گذشته»**
- **جستجو** میان نوبت‌ها
- **خروجی CSV** و **چاپ**
- **لغو** و **جابه‌جایی** نوبت مستقیم از داشبورد

برای اینکه دکمه‌ی «جابه‌جایی» کار کند، صفحه‌ای با شورت‌کد `[pronobat_reschedule]` بسازید.

## شناسایی مشتری

مشتری با کوکی شناسایی می‌شود؛ ترتیب تطبیق: **کاربر وردپرس ← شماره‌ی موبایل ← ایمیل**. هیچ مشتری‌ای نوبت‌های شخص دیگری را نمی‌بیند.

<Callout type="info">
مشتری می‌تواند اطلاعات پروفایل خود (نام و ایمیل) را هم از همین داشبورد ویرایش کند.
</Callout>
