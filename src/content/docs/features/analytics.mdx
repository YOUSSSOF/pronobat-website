# تحلیل قیف رزرو

تحلیل قیف نشان می‌دهد کاربران در مسیر رزرو کجا از فرم بیرون می‌روند، تا نقاط ضعف را برطرف کنید و نرخ تبدیل را بالا ببرید.

![تحلیل قیف رزرو](/images/screenshot-analytics.png)

## گزارش قیف

از مسیر **پرو نوبت ← تحلیل قیف**، تعداد نشست‌ها در هر مرحله، درصد تبدیل و میزان **انصراف** بین مراحل را می‌بینید:

انتخاب خدمت ← انتخاب متخصص ← انتخاب تاریخ ← انتخاب زمان ← اطلاعات مشتری ← تأیید ← رزرو موفق

بازه‌های زمانی **۷ / ۳۰ / ۹۰ روزه** برای مقایسه‌ی روند در دسترس‌اند.

## حریم خصوصی

ردیابی **کاملاً ناشناس** است: تنها یک شناسه‌ی نشستِ بی‌نام ذخیره می‌شود و **هیچ اطلاعات شخصی** ثبت نمی‌گردد. تکرارِ یک مرحله در یک نشست، شمارش را زیاد نمی‌کند.

<Callout type="info">
ردیابی «بی‌سروصدا» (fire-and-forget) است و هرگز روی سرعت یا کارکرد فرم رزرو اثر نمی‌گذارد.
</Callout>
