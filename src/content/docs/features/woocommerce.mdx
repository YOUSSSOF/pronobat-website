# پرداخت با ووکامرس

پرونوبت یک **مدل پرداخت ترکیبی** دارد: اگر ووکامرس فعال باشد، پرداختِ آنلاین می‌تواند از طریق **سفارش مجازی ووکامرس** انجام شود؛ در نبود ووکامرس، درگاه‌های داخلی ایران (زرین‌پال / آیدی‌پی / نکست‌پی) مثل قبل کار می‌کنند.

![تنظیمات پرداخت پرونوبت](/images/screenshot-payments.png)

## حالت پرداخت

از مسیر **پرو نوبت ← تنظیمات ← پرداخت**، «حالت پرداخت» را انتخاب می‌کنید:

| حالت | رفتار |
|---|---|
| **خودکار** | اگر ووکامرس فعال باشد از آن استفاده می‌شود، وگرنه درگاه‌های داخلی |
| **درگاه داخلی** | همیشه زرین‌پال / آیدی‌پی / نکست‌پی |
| **ووکامرس** | همیشه از طریق سفارش ووکامرس (در نبود ووکامرس، بازگشت به درگاه داخلی) |

## چطور کار می‌کند

هنگام رزرو، یک سفارش مجازی ووکامرس با مبلغ نوبت ساخته می‌شود و مشتری به صفحه‌ی پرداخت ووکامرس می‌رود؛ در نتیجه **همه‌ی درگاه‌های ووکامرس** پشتیبانی می‌شوند. پس از پرداخت موفق، نوبت به‌صورت خودکار «تأییدشده» و «پرداخت‌شده» می‌شود؛ لغو یا ناموفق‌شدن سفارش، نوبتِ رزروشده را آزاد می‌کند.

<Callout type="info">
پرداخت‌های ووکامرس در گزارش‌های پرداخت پرونوبت هم ثبت و نمایش داده می‌شوند.
</Callout>

برای دریافت بخشی از مبلغ به‌صورت پیش‌پرداخت، [پیش‌پرداخت / بیعانه](/docs/features/deposits) را ببینید.
