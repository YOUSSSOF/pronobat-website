# شورت‌کدها

## `[pronobat_booking]`

فرم رزرو کامل را نمایش می‌دهد. این شورت‌کد را در هر صفحه یا پست وردپرس قرار دهید.

### ویژگی‌ها

| ویژگی | پیش‌فرض | توضیح |
|---|---|---|
| `service` | — | شناسه‌ی یک سرویس خاص (مرحله‌ی انتخاب سرویس حذف می‌شود) |
| `staff` | — | شناسه‌ی یک کارمند خاص (مرحله‌ی انتخاب کارمند حذف می‌شود) |
| `theme` | — | نام تم پس‌زمینه‌ی ویجت (روی `data-bg-theme` ست می‌شود) |
| `accent` | — | رنگ تأکیدی سفارشی به‌صورت هگز (مثلاً `#378ADD`)؛ در نبود آن از تنظیم `general.booking_accent` استفاده می‌شود |
| `radius` | — | شعاع گردی گوشه‌ها به پیکسل (۰ تا ۸؛ بر اساس سیستم طراحی محدود می‌شود) |

<Callout type="info">
اگر `service` مشخص نشود و فقط یک سرویس در سیستم تعریف شده باشد، همان سرویس به‌صورت خودکار انتخاب می‌شود.
</Callout>

### مثال‌ها

```
[pronobat_booking]
```

```
[pronobat_booking service="3" accent="#E24B4A"]
```

```
[pronobat_booking staff="5" radius="4"]
```

### در Gutenberg

بلاک **ProNobat Booking Form** در ویرایشگر Gutenberg در دسترس است. همان ویژگی‌های شورت‌کد از طریق پنل بلاک قابل تنظیم هستند.

### در Elementor

ویجت **ProNobat Booking** در دسته‌ی **General (عمومی)** پنل Elementor در دسترس است (تنها زمانی که Elementor فعال باشد).

## `[pronobat_appointments]`

لیست نوبت‌های کاربر وارد‌شده را نمایش می‌دهد (تا ۵۰ نوبت اخیر). این شورت‌کد ویژگی (attribute) نمی‌گیرد.

```
[pronobat_appointments]
```

کاربر باید وارد شده باشد و شماره‌ی موبایلش (`pronobat_phone`) با یک مشتری مطابقت داشته باشد. برای نوبت‌های در وضعیت `pending` یا `confirmed`، لینک لغو نمایش داده می‌شود.

---

## `[pronobat_cancel]`

فرم لغو نوبت را نمایش می‌دهد. معمولاً در صفحه‌ای جداگانه قرار می‌گیرد که لینک لغو در ایمیل/پیامک به آن اشاره دارد.

```
[pronobat_cancel]
```

<Callout type="info">
توکن `{cancel_link}` در قالب پیامک و ایمیل به‌طور خودکار URL صفحه‌ای را تولید می‌کند که این شورت‌کد در آن قرار دارد. مطمئن شوید صفحه لغو ساخته شده و شورت‌کد در آن قرار دارد.
</Callout>

---

## `[pronobat_payment_success]` و `[pronobat_payment_failed]`

این دو شورت‌کد صفحه‌ی نتیجه‌ی پرداخت را نمایش می‌دهند و در صفحه‌های `/booking/success` و `/booking/failed` که هنگام فعال‌سازی افزونه به‌صورت خودکار ساخته می‌شوند قرار می‌گیرند. پس از بازگشت از درگاه، کاربر به این صفحه‌ها هدایت می‌شود.

```
[pronobat_payment_success]
```

```
[pronobat_payment_failed]
```

شورت‌کد موفقیت، شناسه‌ی رزرو را از پارامتر `?ref=` می‌خواند و نمایش می‌دهد.
