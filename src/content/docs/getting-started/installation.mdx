# نصب افزونه پرونوبت

## پیش‌نیازها

قبل از نصب، مطمئن شوید محیط شما شرایط زیر را دارد:

| پیش‌نیاز | حداقل نسخه |
|---|---|
| WordPress | ۶.۰ |
| PHP | ۸.۱ |
| MySQL | ۸.۰ یا MariaDB ۱۰.۶ |

افزونه پرونوبت به خروجی‌های PHP اضافی نیاز ندارد فراتر از آنچه وردپرس به آن نیاز دارد. اگر سایت وردپرسی شما اکنون کار می‌کند، احتمالاً پرونوبت هم نصب می‌شود.

<Callout type="info">
پرونوبت یک افزونه‌ی تجاری است و از فروشگاه [راستچین](https://www.rtl-theme.com/product/pronobat/) خریداری می‌شود؛ روی مخزن عمومی وردپرس‌داتارگ موجود نیست. پس از خرید، فایل ZIP را دانلود و طبق روش‌های زیر نصب کنید.
</Callout>

## روش ۱ — آپلود فایل ZIP (پیشنهادی)

۱. **افزونه‌ها ← افزودن افزونه جدید ← بارگذاری افزونه**
۲. فایل `pronobat-x.x.x.zip` دانلود‌شده از راستچین را انتخاب کنید.
۳. روی **نصب** و سپس **فعال‌سازی** کلیک کنید.

## روش ۲ — WP-CLI

```bash
# نصب از فایل ZIP خریداری‌شده
wp plugin install /path/to/pronobat.zip --activate
```

## پیکربندی اولیه

پس از فعال‌سازی، یک منوی سطح‌بالای **پرو نوبت** در پیشخوان وردپرس اضافه می‌شود (به‌همراه زیرمنوها: داشبورد، نوبت‌ها، تقویم، سرویس‌ها، کارمندان، مشتریان، گزارش‌ها، پرداخت‌ها، اعلان‌ها، تنظیمات). برای شروع، از مسیر **پرو نوبت ← تنظیمات** موارد زیر را پیکربندی کنید:

1. **اطلاعات کسب‌وکار** — نام، منطقه زمانی، فرمت تاریخ (تب «عمومی»)
2. **درگاه پرداخت** — فعال‌سازی یک درگاه پیش‌فرض (زرین‌پال، آیدی‌پی، یا نکست‌پی) در تب «درگاه پرداخت»
3. **سرویس پیامک** — انتخاب ارائه‌دهنده و وارد کردن API key در تب «پیامک»
4. **ساعت کاری** — تنظیم ساعت‌های کاری در تب «ساعت کاری»

سپس از زیرمنوهای «سرویس‌ها» و «کارمندان» خدمات و کارکنان خود را تعریف کنید.

## تأیید نصب

برای اطمینان از نصب صحیح:

```bash
wp plugin list | grep pronobat
```

باید خروجی زیر را ببینید:

```
pronobat    active    x.x.x
```

همچنین جداول پایگاه‌داده باید ایجاد شده باشند:

```bash
wp db query "SHOW TABLES LIKE '%pronobat%';" --skip-column-names
```

<Callout type="info">
اگر جداول ایجاد نشدند، افزونه را غیرفعال کرده و دوباره فعال کنید. وردپرس هنگام فعال‌سازی hook `register_activation_hook` را اجرا می‌کند که مسئول ایجاد جداول است.
</Callout>

## حذف نصب

برای حذف کامل:

```bash
wp plugin deactivate pronobat
wp plugin delete pronobat
```

<Callout type="warning">
دستور `wp plugin delete` (یا حذف افزونه از پیشخوان) فایل `uninstall.php` را اجرا می‌کند و **تمام جدول‌ها، تنظیمات، ترنزینت‌ها و نقش‌های پرونوبت را به‌طور غیرقابل‌بازگشت حذف می‌کند**. صرفِ **غیرفعال‌سازی** (`deactivate`) داده‌ها را پاک نمی‌کند. پیش از حذف، در صورت نیاز پشتیبان بگیرید.
</Callout>
