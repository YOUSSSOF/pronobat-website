# تنظیمات پیامک

مسیر: **پرونوبت ← تنظیمات ← پیامک**

## ارائه‌دهنده پیامک

یکی از سه ارائه‌دهنده را انتخاب کنید:

| ارائه‌دهنده | احراز هویت |
|---|---|
| کاوه‌نگار | API Key + خط ارسال |
| ملی‌پیامک | نام‌کاربری / رمز عبور + خط ارسال |
| آی‌پی‌پنل | Access Key + خط ارسال |

## سقف روزانه ارسال

- **پیش‌فرض:** ۵۰۰ پیامک در روز (کلید `sms.daily_cap`)
- این محدودیت از ارسال ناخواسته و هزینه اضافی جلوگیری می‌کند.
- شمارنده در نیمه‌شب (به وقت ایران) ریست می‌شود.

## رویدادهای پیامک

| رویداد | پیش‌فرض |
|---|---|
| نوبت تأییدشده | ✓ فعال |
| نوبت لغوشده | ✓ فعال |
| یادآور ۲۴ ساعته | ✓ فعال |
| تغییر زمان نوبت | ✓ فعال |
| درخواست استرداد تأیید شد | ✓ فعال |

## قالب پیام‌ها

قالب هر پیامک قابل ویرایش است. توکن‌های موجود:

| توکن | مقدار |
|---|---|
| `{booking_ref}` | کد رزرو |
| `{customer_name}` | نام مشتری |
| `{service_name}` | نام خدمت |
| `{staff_name}` | نام کارمند |
| `{date_jalali}` | تاریخ جلالی |
| `{time}` | ساعت نوبت |
| `{price}` | مبلغ |
| `{status}` | وضعیت نوبت |

<Callout type="info">
توکن‌های لینک مانند `{cancel_link}` و `{reschedule_link}` در قالب‌های **ایمیل** در دسترس‌اند.
</Callout>

مثال پیش‌فرض تأییدیه (رویداد `booking.created`):
```
نوبت شما با کد {booking_ref} برای {service_name} در تاریخ {date_jalali} ساعت {time} ثبت شد.
```

## فیلتر کردن پیام قبل از ارسال

آرگومان سوم فیلتر، **شناسه‌ی نوبت** است و نام رویداد به‌صورت `booking.created`، `booking.confirmed`، ... است.

```php
add_filter( 'pronobat_sms_message', function( string $msg, string $event, int $appointment_id ) {
    // اضافه کردن آدرس به پیامک تأییدیه
    if ( $event === 'booking.created' ) {
        $msg .= "\nآدرس: خیابان ولیعصر، پلاک ۱۲";
    }
    return $msg;
}, 10, 3 );
```

## لغو opt-out

اگر مشتری گزینه «دریافت پیامک» را در پروفایل خود غیرفعال کرده باشد، `SmsService` پیامک ارسال نمی‌کند (حتی اگر فیلتر `pronobat_sms_before_send` مقدار `true` برگرداند).
