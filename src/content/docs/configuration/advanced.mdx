# تنظیمات پیشرفته

مسیر: **پرونوبت ← تنظیمات ← پیشرفته**

این تب فیلدهای زیر را در بخش `advanced` تنظیمات کنترل می‌کند:

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `slot_interval` | ۳۰ | فاصله‌ی بازه‌های زمانی (دقیقه) |
| `min_advance_hours` | ۲ | حداقل فاصله‌ی زمانی تا نزدیک‌ترین رزرو (ساعت) |
| `max_advance_days` | ۶۰ | حداکثر تعداد روز برای رزرو در آینده |
| `pending_payment_ttl_minutes` | ۱۵ | مهلت نگه‌داری نوبت در وضعیت پرداخت معلق پیش از پاک‌سازی |
| `cache_ttl_minutes` | ۵ | مدت ماندگاری کش بازه‌ها (دقیقه) |
| `debug_log` | غیرفعال | ثبت لاگ دیباگ پرونوبت |

## حالت دیباگ

وقتی `debug_log` فعال باشد، پرونوبت لاگ‌های دقیق‌تری به `wp-content/debug.log` می‌نویسد. برای دیدن لاگ، WordPress debug را نیز روشن کنید:

```php
// wp-config.php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```

<Callout type="warning">
حالت دیباگ را در محیط تولید روشن نگذارید؛ لاگ‌ها ممکن است اطلاعات حساس داشته باشند.
</Callout>

## کش بازه‌ها (Slot Cache)

محاسبه‌ی بازه‌های خالی پرهزینه است، بنابراین نتیجه در ترنزینت‌های وردپرس با پیشوند `pronobat_slots_` به‌مدت `cache_ttl_minutes` کش می‌شود.

کش به‌صورت **خودکار** پاک می‌شود وقتی: ساعت کاری یا روز تعطیل کارمند تغییر کند، سرویسی ویرایش/حذف شود، نوبتی ثبت/لغو/جابه‌جا شود، یا هر تب از تنظیمات ذخیره شود.

برای پاک‌سازی دستی از WP-CLI:

```bash
wp transient delete --all
```

## محدودیت نرخ (Rate Limiter)

مسیرهای عمومی REST به‌صورت پیش‌فرض و درون‌ساخت محدود می‌شوند (این مقادیر در کد افزونه ثابت‌اند):

| مسیر | حد |
|---|---|
| `GET /public/slots` | ۱۰ درخواست در دقیقه به ازای IP |
| `POST /public/appointments` | ۳ درخواست در دقیقه به ازای IP |
| `GET /public/services` · `GET /public/staff` | ۳۰ درخواست در دقیقه به ازای IP |

## رفتار cron

این کارهای زمان‌بندی‌شده به‌صورت خودکار اجرا می‌شوند (زمان‌بندی ثابت است):

| کار | زمان‌بندی |
|---|---|
| یادآور نوبت | ساعتی — پنجره‌ی ۲۴ ساعت و ۱ ساعت پیش از نوبت |
| پاک‌سازی (لاگ قدیمی و پرداخت معلق منقضی) | ساعتی |
| گزارش هفتگی برای مدیر | شنبه، ۸ صبح به وقت تهران |
