# تنظیمات ایمیل

مسیر: **پرونوبت ← تنظیمات ← ایمیل**

پرونوبت از سیستم WP Mail وردپرس برای ارسال ایمیل استفاده می‌کند. برای ارسال قابل‌اعتماد، پیشنهاد می‌شود از یک افزونه SMTP مانند **WP Mail SMTP** استفاده کنید.

## رویدادهای ایمیل مشتری

| رویداد | پیش‌فرض |
|---|---|
| تأیید نوبت | ✓ فعال |
| لغو نوبت | ✓ فعال |
| یادآور ۲۴ ساعته | ✓ فعال |
| تأیید استرداد | ✓ فعال |

## رویدادهای ایمیل مدیر

| رویداد | پیش‌فرض |
|---|---|
| نوبت جدید ثبت شد | ✓ فعال |
| نوبت لغوشده | ✓ فعال |
| پرداخت ناموفق | ✓ فعال |

## قالب ایمیل

ایمیل‌ها با قالب HTML داخلی افزونه (در `EmailService`) و در جهت RTL ارسال می‌شوند. گزینه‌های قابل تنظیم در تب ایمیل:

| فیلد | کلید | توضیح |
|---|---|---|
| نام فرستنده | `email.from_name` | نام نمایش‌داده‌شده‌ی فرستنده |
| آدرس فرستنده | `email.from_address` | آدرس From |
| متن پاورقی | `email.footer_text` | متن انتهای همه‌ی ایمیل‌ها |
| لوگو | `email.logo_id` | شناسه‌ی رسانه‌ی لوگو |
| ارسال HTML | `email.html_enabled` | روشن/خاموش بودن قالب HTML |

برای ارسال قابل‌اعتماد، SMTP را در همین تب فعال کنید (`email.smtp_enabled` و فیلدهای `email.smtp_host/port/user/pass/encryption`).

## توکن‌های قالب

همان توکن‌های پیامک در قالب ایمیل هم کار می‌کنند: `{booking_ref}`، `{customer_name}`، `{service_name}`، `{staff_name}`، `{date_jalali}`، `{time}`. علاوه بر آن در ایمیل، توکن‌های لینک نیز در دسترس‌اند:

| توکن | مقدار |
|---|---|
| `{cancel_link}` | لینک لغو نوبت |
| `{reschedule_link}` | لینک جابه‌جایی/رزرو مجدد |

## آزمایش ارسال

در صفحه تنظیمات ایمیل، دکمه **ارسال ایمیل آزمایشی** وجود دارد که یک ایمیل نمونه به آدرس ادمین می‌فرستد.
