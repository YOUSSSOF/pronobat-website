# تنظیمات زبان و منطقه

مسیر: **پرونوبت ← تنظیمات ← زبان و منطقه**

## زبان افزونه

نوبت به‌طور پیش‌فرض از زبان وردپرس پیروی می‌کند. اگر وردپرس روی `fa_IR` تنظیم شده باشد، رابط کاربری، پیامک‌ها، و ایمیل‌ها به فارسی ارسال می‌شوند.

## تقویم

| گزینه | توضیح |
|---|---|
| جلالی (شمسی) | پیش‌فرض برای `fa_IR` — تمام تاریخ‌ها به شمسی نمایش داده می‌شوند |
| میلادی | برای کاربران بین‌المللی |

تقویم جلالی از `morilog/jalali` استفاده می‌کند و تمام تبدیل‌ها در `src/Services/JalaliCalendar.php` انجام می‌شوند.

## اعداد فارسی

وقتی گزینه‌ی اعداد فارسی فعال باشد (کلید `localization.persian_digits`، پیش‌فرض روشن)، تمام اعداد رو‌به‌روی کاربر (تاریخ، ساعت، مبلغ) به اعداد فارسی (۰۱۲۳۴۵۶۷۸۹) نمایش داده می‌شوند. برای غیرفعال کردن، این گزینه را در **تنظیمات ← زبان و منطقه** خاموش کنید.

## نام ماه‌ها

کلید `localization.persian_months` نحوه‌ی نمایش نام ماه‌های جلالی را تعیین می‌کند (`full` به‌صورت پیش‌فرض).

## RTL / LTR

- پنل مدیریت پرونوبت همیشه RTL است.
- فرم رزرو عمومی جهت را از `<html dir>` ارث می‌برد.
- کلید `localization.rtl_override` (پیش‌فرض `auto`) امکان بازنویسی جهت را می‌دهد.

## تقویم جلالی

فعال یا غیرفعال بودن تقویم جلالی با کلید `localization.jalali_enabled` (پیش‌فرض روشن) کنترل می‌شود. قالب‌بندی تاریخ‌ها از توکن‌های جلالی مانند `jY/jm/jd` در `JalaliCalendar` استفاده می‌کند.
