# یکپارچه‌سازی ملی‌پیامک

## پیش‌نیازها

- حساب کاربری در [melipayamak.com](https://melipayamak.com)
- خط اختصاصی یا اشتراکی برای ارسال

## احراز هویت

پرونوبت برای ملی‌پیامک از روش **نام‌کاربری / رمز عبور** (REST API پیامک‌پنل) استفاده می‌کند.

مسیر: **پرونوبت ← تنظیمات ← پیامک ← ملی‌پیامک**

| فیلد | کلید تنظیمات | توضیح |
|---|---|---|
| نام‌کاربری | `sms.melipayamak.username` | نام‌کاربری پنل ملی‌پیامک |
| رمز عبور | `sms.melipayamak.password` | رمز عبور پنل |
| خط ارسال | `sms.melipayamak.sender` | شماره خطی که پیامک از آن ارسال می‌شود |

<Callout type="info">
پیام‌ها به‌صورت متن آزاد ارسال می‌شوند؛ ملی‌پیامک API الگوی اختصاصی ندارد و توکن‌های متن از مسیر اعلان‌ها جای‌گذاری می‌شوند.
</Callout>

## آزمایش ارسال

در صفحه تنظیمات پیامک، دکمه **ارسال پیامک آزمایشی** موجود است.

## خطاهای رایج

| کد | معنی |
|---|---|
| `0` | خطای نامشخص |
| `1` | موفق |
| `-1` | نام‌کاربری یا رمز اشتباه |
| `-2` | اعتبار ناکافی |
| `-3` | خط ارسال نامعتبر |
| `-4` | شماره مقصد نامعتبر |
