# یکپارچه‌سازی فراز اس‌ام‌اس

فراز اس‌ام‌اس روی بستر آی‌پی‌پنل کار می‌کند و احراز هویت آن با **Access Key** انجام می‌شود.

## پیش‌نیازها

- حساب کاربری در [farazsms.com](https://farazsms.com)
- Access Key از پنل، بخش «کلید وب‌سرویس»
- خط اختصاصی یا اشتراکی

## پیکربندی در نوبت

مسیر: **پرونوبت ← تنظیمات ← پیامک ← فراز اس‌ام‌اس**

| فیلد | توضیح |
|---|---|
| API Key فراز (AccessKey) | کلید دسترسی از پنل فراز اس‌ام‌اس |
| خط ارسال | شماره خط ارسالی شما |

## تنظیم خط ارسال

خط ارسال باید با فرمت `+98XXXXXXXXXX` وارد شود. مثال: `+982100000000`

## ارسال با الگو (پترن)

برای پیام‌های خدماتی، فراز اس‌ام‌اس از ارسال مبتنی بر الگوی تأییدشده پشتیبانی می‌کند (کد الگو + مقادیر). این مسیر برای تحویل سریع‌تر پیام‌های نوبت توصیه می‌شود.

## آزمایش ارسال

در صفحه تنظیمات پیامک، دکمه **ارسال پیامک آزمایشی** وجود دارد.

<Callout type="info">
فراز اس‌ام‌اس ارسال به شماره‌های رند (مثل ۰۹۱۲۰۰۰۰۰۰۰) را محدود می‌کند. در صورت خطای مداوم، ارسال آزمایشی را با یک شماره واقعی تست کنید.
</Callout>
