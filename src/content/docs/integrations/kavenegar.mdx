# یکپارچه‌سازی کاوه‌نگار

## پیش‌نیازها

- حساب کاربری در [kavenegar.com](https://kavenegar.com)
- API Key از پنل «تنظیمات → API Key»

## پیکربندی در نوبت

مسیر: **پرونوبت ← تنظیمات ← پیامک ← کاوه‌نگار**

| فیلد | توضیح |
|---|---|
| API Key | کلید API از پنل کاوه‌نگار |
| خط ارسال | شماره خطی که پیامک از آن ارسال می‌شود |

## متن پیام‌ها

پرونوبت پیامک‌ها را به‌صورت **متن آزاد** با متد `Send` کاوه‌نگار ارسال می‌کند (نه از طریق الگوهای تأییدشده/VerifyLookup). بنابراین فیلد جداگانه‌ای برای «نام قالب» در تنظیمات وجود ندارد.

متن هر رویداد (ثبت، تأیید، یادآور، لغو و ...) از مسیر **پرونوبت ← اعلان‌ها** قابل ویرایش است و توکن‌هایی مانند `{customer_name}` و `{date_jalali}` در آن جای‌گذاری می‌شوند.

<Callout type="info">
برای ارسال متن آزاد، خط ارسالی شما در کاوه‌نگار باید از پیام‌های خدماتی/تبلیغاتی متنی پشتیبانی کند. اگر فقط خط الگو (پترن) دارید، با پشتیبانی کاوه‌نگار درباره‌ی خط مناسب برای ارسال متن آزاد مشورت کنید.
</Callout>

## آزمایش ارسال

در صفحه تنظیمات پیامک، دکمه **ارسال پیامک آزمایشی** وجود دارد که یک پیامک نمونه به شماره‌ای که وارد می‌کنید ارسال می‌کند.

## اعتبار کافی

<Callout type="warning">
قبل از راه‌اندازی در محیط تولید، مطمئن شوید که اعتبار حساب کاوه‌نگار کافی است. در صورت کمبود اعتبار، ارسال پیامک بی‌صدا شکست می‌خورد.
</Callout>

## خطاهای رایج

| کد | معنی | راه‌حل |
|---|---|---|
| `200` | موفق | — |
| `401` | API Key نامعتبر | کلید را بررسی کنید |
| `403` | اعتبار ناکافی | حساب را شارژ کنید |
| `404` | شماره نامعتبر | فرمت `09XXXXXXXXX` را بررسی کنید |
| `412` | پارامتر ناقص | خط ارسال را بررسی کنید |
