# یکپارچه‌سازی SMS.ir

## پیش‌نیازها

- حساب کاربری در [sms.ir](https://sms.ir)
- کلید وب‌سرویس (API Key) از پنل، بخش «توسعه‌دهندگان»
- یک شماره خط (Line Number) فعال

## پیکربندی در نوبت

مسیر: **پرونوبت ← تنظیمات ← پیامک ← SMS.ir**

| فیلد | توضیح |
|---|---|
| API Key پیامک | کلید وب‌سرویس از پنل SMS.ir |
| شماره خط ارسال | همان Line Number شما (در فیلد «خط ارسال») |

## ارسال متنی و الگو (پترن)

- **ارسال گروهی متنی:** برای پیام‌های متن آزاد از سرویس ارسال انبوه استفاده می‌شود.
- **ارسال با الگو (Verify):** برای پیام‌های خدماتی نوبت می‌توانید از الگوهای تأییدشده با شناسه قالب (`templateId`) و پارامترها استفاده کنید که تحویل سریع‌تری دارند.

## آزمایش ارسال

در صفحه تنظیمات پیامک، دکمه **ارسال پیامک آزمایشی** وجود دارد که یک پیامک نمونه به شماره‌ی واردشده ارسال می‌کند.

<Callout type="info">
کلید API از هدر `X-API-KEY` ارسال می‌شود و «شماره خط ارسال» در تنظیمات همان Line Number عددی شماست.
</Callout>

<Callout type="warning">
قبل از راه‌اندازی در محیط تولید، از کافی بودن اعتبار حساب SMS.ir مطمئن شوید؛ در صورت کمبود اعتبار، ارسال پیامک شکست می‌خورد.
</Callout>
