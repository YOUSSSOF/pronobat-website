# یکپارچه‌سازی نکست‌پی

## پیش‌نیازها

- حساب کاربری در [nextpay.org](https://nextpay.org)
- API Key از پنل «تنظیمات → API»

## پیکربندی در نوبت

مسیر: **پرونوبت ← تنظیمات ← پرداخت ← نکست‌پی**

| فیلد | توضیح |
|---|---|
| API Key | کلید API از پنل نکست‌پی |

## استرداد دستی

<Callout type="warning">
نکست‌پی از **استرداد خودکار** پشتیبانی نمی‌کند (`supports_refund()` مقدار `false` برمی‌گرداند). هنگامی که درخواست استرداد روی یک تراکنش نکست‌پی ثبت شود، endpoint استرداد با کد خطای `pronobat_refund_manual` و وضعیت HTTP `422` پاسخ می‌دهد. توجه: این یک **کد خطا** است، نه یک هوک قابل‌اتصال.
</Callout>

فرآیند استرداد دستی:

1. پرونوبت ← پرداخت‌ها → تراکنش موردنظر را باز کنید
2. شماره مرجع درگاه (`gateway_ref`) را یادداشت کنید
3. وارد پنل نکست‌پی شوید
4. تراکنش را با شماره مرجع پیدا کنید
5. از پنل نکست‌پی استرداد را انجام دهید
6. وضعیت پرداخت/نوبت را به‌صورت دستی به `refunded` تغییر دهید

<Callout type="info">
برای درگاه‌هایی که استرداد خودکار دارند (زرین‌پال، آیدی‌پی) می‌توانید پس از استرداد موفق با اکشن `pronobat_payment_refunded` واکنش نشان دهید. برای نکست‌پی هیچ هوک خودکاری برای حالت استرداد دستی فعال نمی‌شود؛ بنابراین اطلاع‌رسانی باید بخشی از فرایند دستی شما باشد.
</Callout>
